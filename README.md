# weather-app

This app shows National Weather Service forecasts for US locations. NWS is the classical physics based approach that's been running global weather prediction for decades. The newer machine learning side is [Google DeepMind's WeatherNext](https://developers.google.com/weathernext/), which now powers Google's own weather features. v1 shows the traditional forecasts while [v2 (#3)](https://github.com/williamcs50/weather-app/issues/3) will add WeatherNext next to them so you can see where they agree and where they differ.


## How it was built

Scaffolded with Claude inside VS Code, integrated, reviewed, and shipped by me.
